# agoralar-store-json

JSON-хранилище для ядра [AxisLar](https://github.com/authorlarciss/AxisLar):
файл + эталонная семантика ядра. Плагин продукта
[AgoraLar](https://github.com/authorlarciss/AgoraLar).

Устанавливается как обычный пакет; продукт находит плагин через entry point
`agoralar.storage` и проверяет совместимость по `CONTRACT_VERSION` ядра.
