# ADR-0013: Манифест плагина — данные, а не DTO продукта

## Контекст

ADR-0011 зафиксировал: точка входа плагина возвращает `PluginManifest` —
DTO **продукта**. При выносе встроенных бэкендов (`json`, `sqlite`) в
отдельные пакеты выяснилось, что это заставляет плагин импортировать
`agoralar`, то есть зависеть от продукта, а не только от контракта ядра.
Нарушается главная граница экосистемы: ядро → продукт → плагины, где
плагин знает только ядро.

## Решение

1. **Плагин объявляет манифест как данные** — словарь с ключами:

   ```python
   def plugin() -> dict[str, object]:
       return {"requires_contract": ">=2,<3", "factory": create}
   ```

   Имя плагина берётся из имени entry point, вид — из группы
   (`agoralar.storage` / `agoralar.source`). Плагину не нужны DTO продукта.

2. **Продукт строит `PluginManifest` сам**: валидирует ключи, подставляет
   `name` и `kind`, отклоняет плагин с понятной причиной, если данных не
   хватает или они неверного типа.

3. **Обратная совместимость:** продукт по-прежнему принимает и
   `PluginManifest` (встроенные/тестовые плагины), и callable, который его
   возвращает. Словарь — предпочтительная форма для сторонних пакетов.

4. **Зависимости плагина:** только `axislar-core` (и его контракт
   `axislar_core.contracts`). Ни `agoralar`, ни его DTO.

## Альтернативы

- **Оставить `PluginManifest` в продукте и требовать импорт продукта.**
  Проще для кода, но плагин начинает зависеть от оболочки: версии продукта
  и плагина связываются, а смена продукта ломает плагины. Отклонено.
- **Перенести `PluginManifest` в ядро.** Ядро не знает про плагины и
  entry points — это продуктовое понятие. Отклонено.
- **Требовать у плагина отдельный модуль-манифест с фиксированным именем.**
  Дублирует механизм entry points. Отклонено.

## Последствия

Плюсы: плагин зависит только от ядра; манифест описывается в терминах
данных (легко генерировать, легко проверять); продукт остаётся свободным
в выборе DTO.

Минусы: `requires_contract` не типизирован статически — проверка целиком в
рантайме (поэтому реестр даёт внятные причины отказа и тесты на каждую
форму манифеста); `factory` из словаря — `object`, нужен `cast` внутри
продукта.

## Статус

Принято.
